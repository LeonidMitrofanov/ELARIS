Приложение для wellness-бренда космецевтики и нутрицевтики: разбор кожи,
подбор добавок, рутина ухода, магазин, клуб по подписке.

## С чего начинать

Прочитать разбор, а не задание: задание большое и написано списком желаний,
разбор говорит, с чего начинать и какие решения нужны от заказчика до кода.
